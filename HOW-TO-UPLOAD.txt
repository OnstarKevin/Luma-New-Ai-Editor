工作流程 / Workflow：
  1. 打开本文件夹
  2. 全选 → 复制
  3. 粘贴到仓库根目录，覆盖同名文件
  4. git add . && git commit -m "update" && git push

  或者直接在 GitHub Web 上逐个拖拽替换。


快捷操作 / Shortcuts：
  Shift+ArrowUp/Down  在块之间扩展选择
  Ctrl+Shift+A         全选所有块
